# heartflow

Rust 实现的终端 AI agent，命令名 `hf`。这里是 GitHub Wiki 种子首页——保持精简，长文档一律以文档站为准，避免双份内容漂移。

## 权威文档

- 📖 文档站（用户手册 + 架构）：<https://santachains.github.io/heartflow/>
- 🔧 API 文档（rustdoc）：<https://santachains.github.io/heartflow/api/>
- 🤖 AI 可读索引：<https://santachains.github.io/heartflow/llms.txt>
- 💻 源码仓库：<https://github.com/SantaChains/heartflow>

## 快速上手

```powershell
scoop bucket add heartflow https://github.com/SantaChains/heartflow
scoop install heartflow
hf --provider deepseek
```
